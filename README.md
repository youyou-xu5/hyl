# Memory Album Export

This folder is a static memory album generated by Memory Album DIY.

## English

- Upload the whole folder to Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any static host.
- The pages are plain HTML/CSS/JS. There is no backend and no tracking.
- The optional letter access code is only a front-end privacy curtain. It is not encryption.

## 中文

- 可以把整个文件夹上传到 Vercel、Netlify、GitHub Pages、Cloudflare Pages 或任意静态托管。
- 页面是纯 HTML/CSS/JS，没有后端，也没有追踪代码。
- 私密信件的访问口令只是前端遮挡，不是加密安全边界。
